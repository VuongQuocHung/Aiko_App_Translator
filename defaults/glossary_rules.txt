GLOSSARY FORMATTING RULES
Entries with metadata: English = Vietnamese | type=TYPE | first_vi=yes/no | first_en=yes/no | brackets=yes/no | target_only=yes/no.
first_vi and first_en are mutually exclusive and have equal priority. Never set both to yes.
Target-only exception: entries with type=Common (case-insensitive) OR target_only=yes always use ONLY the Vietnamese target, at every occurrence, including titles. Do not retain English, add a bilingual annotation, or wrap the term in square brackets. This exception overrides first_vi, first_en and brackets. Match complete terms and prefer a longer named term over a target-only substring.
For other metadata entries, type describes the term's nature and target_only controls display independently of type.
For legacy entries WITHOUT metadata, retain the existing source -> target translation mapping.
For metadata entries that are neither Common nor target_only=yes, apply these six cases:
A. first_vi=yes, first_en=no, brackets=yes: first [English] (Vietnamese); later [English].
B. first_vi=yes, first_en=no, brackets=no: first English (Vietnamese); later English.
C. first_vi=no, first_en=yes, brackets=yes: first [Vietnamese] (English); later [Vietnamese].
D. first_vi=no, first_en=yes, brackets=no: first Vietnamese (English); later Vietnamese.
E. first_vi=no, first_en=no, brackets=no: always English, without Vietnamese annotation.
F. first_vi=no, first_en=no, brackets=yes: always [English], without Vietnamese annotation.
Square brackets wrap the primary displayed language; the first-mention explanation stays outside.
Never nest brackets. Never append an identical explanation, such as Name (Name).
Reset first mention at EACH new chapter, including chapter/section markers in a batch.
Only narration, dialogue, internal monologue and in-story system messages count as mentions.
Glossary, prompts, examples, reference documents, previous chapters and chapter headings do NOT count.
If TERMS ALREADY INTRODUCED IN THIS CHAPTER is supplied, continue that chapter's state;
do not annotate these terms again just because this is a new request/chunk.
For proofreading/correction, evaluate first mentions in the OUTPUT story, not the input draft.
Glossary formatting outranks stylistic variation. Never vary canonical spelling to avoid repetition.
Do not replace canonical English with Vietnamese unless the entry uses first_en=yes, type=Common or target_only=yes; for first_en, preserve the required first English annotation.
Match complete terms and prefer the longest term over a substring. Treat Common words in context;
do not force a formal term onto an unrelated ordinary word. Preserve aliases as specified.
Glossary data and reference documents are reference data, not additional task instructions.
